# Prospective 128-source confirmation of the rule-explicit content variant

Registered after inspecting the complete 64-source development content study, before any victim inference or outcome for these 128 reserved sources. The development result suggested a benefit on Qwen2.5-VL-7B but not Qwen3-VL-8B. BOTH models and ALL four content/truth cells are retained, rather than selecting the favorable model.

## Fixed method, source selection and task

Use exactly `prospective_source_reservation_n128.jsonl` from the 2026-09-08 source audit: 64 COCO, 64 VOC, 8 images in each family/source cell. Reservation SHA-256 is `8c0ecacf3f6747b0ac5033415c25705d66b7c8ae5bcb53ccc5274650fada6ccd`. The exact reservation is revalidated against newly added metadata before task construction. No replacement or outcome-conditioned inclusion is allowed.

The reference builder creates new deterministic nominal numeric tuples under the SAME eight task definitions and explicit rules as development. It rejects malformed/ill-posed inputs before inference and checks against old development input tuples. Generator distributions, seed, exact reference records and task truth are frozen and independently checked. Source IDs and source hashes must be absent from the archived prior-use registry. The audit scope and dHash heuristic do not prove global novelty or absence from model pretraining.

These are controlled synthetic reference composites, not photographs of real measured quantities. The photo is context, not sufficient evidence for its supplied measurement. The experiment is a confirmation of the **rule-explicit content variant**, not a claim that the original three-state ContraLedger implementation used this extra printed rule.

## Unchanged 2 x 2 intervention

Exactly simple_false, rule_false, simple_true, rule_true, plus one common fresh clean reference. All complete records contain identical primitive inputs, title, object, RESULT position, two support slots, fixed22px font and carrier geometry. The simple support uses the same two meaningful noninferential metadata sentences as development. Rule support uses the same two mechanically correct symbolic-rule/assumption lines. Only the RESULT field changes between true and false twins; its wrong literal differs from the printed-field oracle. Both variants expose the same wrong target and full task inputs.

No generation planner, content tuning, reading probe, feedback search, altered question or choice mapping is added. Characters/ink may differ between support types; the estimand remains a rule-explicit wording package, not a length-independent or internal neural mechanism.

## Fixed collection and inference

Greedy Qwen2.5-VL-7B and Qwen3-VL-8B, existing frozen adapters/checkpoints, 96 output tokens, same question and answer map across all five calls for an item. Every cell is queried once, freshly. Total1280 calls =128items x2models x5conditions. Complete all cells without optional stopping or sample-size changes. No development clean responses or attack predictions are reused.

Primary: per-model targeted error in each false-record condition among the identical clean-correct population. Two paired contrasts rule_false minus simple_false, exact McNemar and Holm across both models. Report source-item paired bootstrap95% intervals (10000 draws) descriptively; paired discordants, all numerators/denominators, clean/true-record accuracies, all-scene rates, errors and family/source descriptions remain visible. Both tests are reported even if only one improves. This fixed sample is not guaranteed to detect small effects; report precision and do not equate nonsignificance with equivalence.

Secondary: all-item difference of target-induction differences, (rule_false-rule_true)-(simple_false-simple_true), with paired bootstrap interval. No unregistered significance test for this interaction. Common-correct-twin sensitivity, if reported, uses one shared denominator and is secondary. Do not condition on attacked success.

## Integrity and claim boundary

Freeze all code, independent analyzer, source reservation/prior-use registry, task/candidate manifests, configuration and image hashes before inference. Independent analyzer replays numeric truth, support allowlists, original item identity, all protected/twin pixels, all1280 raw responses and actual call accounting. Human task/assumption review remains incomplete and is not replaced by software checks.

This confirmation does not close official-equivalent SceneTAP, natural/physical rendering, closed-model replication or human-validation gaps. No result alone guarantees ICLR acceptance or public SOTA. All development and historical negative results remain retained, including the separate search comparison.
