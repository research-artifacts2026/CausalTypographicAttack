# Synthetic natural-render pilot

These three images are **AI-edited synthetic natural renders**, not camera
photographs of a real attack.  They test whether the typography effect
survives a more scene-integrated carrier with perspective, material texture,
environmental lighting, and contact shadows.  They must never be described as
real physical capture.

`registry.json` is the evidence boundary.  It records the exact source and
output hashes, literal printed text, verification question, generator role,
and full edit prompt.  The source and edited images are checked in so the
pilot remains auditable even if the image-generation service changes.

The current set has only three qualitative cases (airplane, train, cat).  It
is suitable for a renderer feasibility figure and a non-headline model pilot;
it is not a substitute for the registered 30-question/450-photo physical
capture protocol or for a powered statistical comparison.
